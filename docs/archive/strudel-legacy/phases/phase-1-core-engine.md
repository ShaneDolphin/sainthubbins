# Phase 1 — Core Engine (Pattern + Controls + Signals + Scheduler)

> Duration: 3-4 weeks. Depends on Phase 0. This is the largest, highest-risk phase — the entire musical semantics live here.

## Objective

Port `pattern.mjs` (4191 LOC), `controls.mjs` (3319 LOC), `signal.mjs` (1099 LOC), `cyclist`/`zyklus`/`schedulerState`/`euclid`/`pick`/`evaluate` so that `Pattern.query(State) -> []Hap` is bit-identical to JS.

## 1.1 Pattern Core (`pattern.mjs`)

Split into multiple files to stay navigable:

| File | Contents |
|------|----------|
| `pattern_core.go` | `type Pattern struct { Query func(State) []Hap; Steps *Fraction }`, `Pure`, `Reify`, `Fmap`/`WithValue`, `WithState`, `AppLeft`/`AppRight`, `Bind`/`SqueezeBind` |
| `pattern_time.go` | `Fast`/`Slow`/`Early`/`Late`/`Off`/`Ply`/`When`/`Every`/`Compress`/`Zoom`/`RepeatCycles` |
| `pattern_structure.go` | `Stack`/`Cat`/`FastCat`/`SlowCat`/`Seq`/`Polymeter`/`Arrange`/`Palindrome` |
| `pattern_random.go` | `Rand`/`Choose`/`DegradeBy`/`SometimesBy`/`Shuffle` (+ `pick.mjs`) |
| `pattern_filter.go` | `Filter`/`RemoveUndefineds` etc. |
| `pattern_steps.go` | `Steps` tracking (`withSteps`, `hasSteps`) |

**Key invariants to preserve**:
- `Pattern` is immutable; all combinators return new `Pattern`.
- `Steps` is `*Fraction` (`nil` = undefined) and propagates via `withSteps`.
- `reify`: string → mini parse if `stringParser` set; otherwise `Pure(string)`.
- `query` is pure; no goroutine state.

**Testing strategy**:
- Use `goja` bridge in `pattern_test.go`: run JS `pattern.mjs` via `goja` to generate expected `[]Hap` for fixtures; compare Go output.
- Port `packages/core/test/pattern.test.mjs` (1394 LOC) case-for-case. Snapshot via `testdata/pattern/*.json`.

## 1.2 Controls (`controls.mjs` 3319 LOC, 295 params)

Do **not** hand-write 295 functions. Code-generate.

```bash
# tools/gen-controls/main.go
# Input: ../js/packages/core/controls.mjs
# Parse `createParam("note")` / `createParam(["n","note"])` calls via regex or tree-sitter
# Output: internal/core/controls_gen.go
```

Generated file shape:

```go
// Code generated by tools/gen-controls — DO NOT EDIT.
package core

func S(v any) Pattern { return Pure(map[string]any{"s": v}) }
func Note(v any) Pattern { return Pure(map[string]any{"note": v}) }
// ... 293 more
// Aliases: N -> Note, etc.
```

- Preserve `createParam` multi-name semantics: `isMulti` + array handling.
- Each control returns `Pattern` wrapping a bag; chaining merges bags via `unionWithObj`.

**Gate**: `go test -run TestControls` verifies bag merging and alias equivalence against JS.

## 1.5 Scheduler (`zyklus.mjs` 54 LOC, `cyclist.mjs`, `clockworker.js`, `schedulerState.mjs` 53 LOC)

```go
// scheduler.go
type Clock struct {
    CPS     float64
    Ticker  *time.Ticker
    mu      sync.Mutex
    Now     Fraction // cycles
}
func NewClock(cps float64) *Clock
func (c *Clock) Start(ctx context.Context, out chan<- []Hap, pattern func() Pattern)
func (c *Clock) SetCPS(cps float64)
func (c *Clock) Stop()

type SchedulerState struct { /* mirrors schedulerState.mjs */ }
```

- JS `clockworker.js` is a Web Worker; Go uses a goroutine + `time.Ticker` at ~20ms resolution (configurable).
- CPS (cycles per second) drives `Now` advancement.
