# Attribution

This project, **Saint Hubbins**, was originally inspired by and ported from
[Strudel](https://codeberg.org/uzu/strudel) (https://strudel.cc), a live-coding
music environment — a JavaScript port of TidalCycles.

- Upstream: https://codeberg.org/uzu/strudel
- Original license: AGPL-3.0-or-later
- This fork retains AGPL-3.0-or-later (see `LICENSE`).

Saint Hubbins is a fundamentally distinct product. No Strudel command,
REPL workflow, `codeberg.org/uzu/strudel-go` import path, or `@strudel/*`
npm package name is supported here. References to Strudel have been removed
from all user-visible surfaces (CLI, web console, docs, templates, package
names) to avoid confusion. A single attribution in this file satisfies the
AGPL requirement in place of scattered per-file `Ported from …` headers.

If you are looking for Strudel, see https://strudel.cc and
https://codeberg.org/uzu/strudel.
